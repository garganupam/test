# Factorial Calculator

A simple program that calculates the factorial of a non-negative integer.

## Description

This project computes the factorial of a given number using an efficient implementation. The factorial of a number `n` is the product of all positive integers less than or equal to `n`.

For example:

- `5! = 5 × 4 × 3 × 2 × 1 = 120`
- `0! = 1`

## Features

- Computes factorials of non-negative integers.
- Simple and easy-to-understand implementation.
- Lightweight with no external dependencies.

## Usage

1. Run the program.
2. Enter a non-negative integer.
3. The program displays the factorial of the entered number.

### Example

**Input**
```text
5
```

**Output**
```text
120
```
